# Researcher role

The researcher converts Hermes observations into durable contracts. Record the
exact reference version, environment, terminal dimensions, inputs, outputs,
timing where observable, and sanitization decisions.

Research output is not a feature request written from intuition. It is an
observation, a trace, a golden frame, a bounded unknown, or a clear blocker. Do
not store credentials, private transcripts, or raw provider payloads.

The researcher should prefer repeatable probes over screenshots and should mark
which details are stable across repeated runs.
