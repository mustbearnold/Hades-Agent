## Pitfalls learned (all fixed, do not re-learn)

1. **Rendered-screen waits** for typed-text markers (`wait_for_rendered`);
   raw-buffer matching fragments under the animated logo. Startup-marker
   waits stay raw (contiguous first frame).
2. **`write_bytes` loses partial progress on EAGAIN** — for large bounded
   PTY writes (osc52 timing 256KiB/512KiB payloads), track the offset
   yourself with raw `rustix::io::write` + EAGAIN sleep loop (see
   `write_bounded` in replay_osc52_timing_limits.rs).
3. **Format-string brace counting** — subagents keep mangling SSE payloads
   built with `format!`/raw strings. Use byte concatenation like the Python
   (see `first_stream_chunks` in replay_tool_call_deltas.rs).
4. **PATH override** must use `std::env::join_paths` (':' on Unix), never
   `MAIN_SEPARATOR` (that's '/').
5. **Parity report shape must byte-match Python** — `observation_id`/
   `terminal`/`unknowns` vs `contract_observation`/`dimensions` vary per
   replay; read the Python's `main()` report dict and mirror it exactly.
   `check_replay_parity.py` normalizes only `pre_delay_ms`,
   `observed_transition_ms`, `response_elapsed_ms`, `response_write_ms`,
   `query_offset`, `da1_query_offset`, `raw_delta`, `screen_tail`.
6. **ExitStatus is not Serialize** — map to `{"kind": "exit"/"signal"/"other"}`.
7. **Subagent file-sweep hazard** — `git add -A` can commit sibling
   subagents' in-flight bins; add explicit paths only. Subagents also
   opportunistically clippy-fix already-committed files — review diffs.
8. **`just verify` takes ~18 min** — run in background
   (`terminal background=true notify_on_complete`); a stale-run artifact
   (mid-edit tree) fails the check phase; re-run on clean tree. Gate
   history (2026-08-05 night):
   - `verify-full4.log` — FAIL (EXIT 101, stale mid-edit clippy; fixed)
   - `verify-full5.log` — FAIL (GATE_EXIT 101) for ONE reason only:
     `replay_tool_call_deltas::server_answers_follow_up_with_plain_completion`
     (records.len()==1 assertion, fixed in `f413181`); **zero
     `"passed": false` in any replay report** — all 19 new ports passed
     their differential checks inside the full gate.
   - `verify-full6.log` (proc_12cda680a297) — fresh run on the fixed
     tree, launched after the fix; its `GATE_EXIT:` line is the
     authoritative verdict for the morning.
9. **Ledger ids can mislabel** — the encode script mislabeled HAD-162
