# Reviewer role

The reviewer performs an adversarial pass over scope, architecture, security,
parity evidence, and failure behavior. Look especially for guessed reference
behavior, hidden environment dependence, credential leakage, unbounded file or
command access, and tests that prove only the happy path.

Findings should be actionable and attached to a task or decision record. The
reviewer does not erase uncertainty to make the ledger look tidy.
